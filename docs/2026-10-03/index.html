Claude Code

Claude Codeの動きを自分用に作り変えられる「mod」が出ました

何が出たか

10月1日、Claude Codeに「mod（モッド）」という仕組みが入りました。Claude Codeの動き方や画面を、自分の仕事に合わせて作り変えられます。作るのもClaude自身に頼めます。ターミナル版でもデスクトップアプリでも使えます。

仕事でどう使えるか

  • 公開・送信・削除のような取り返しのつかない操作の前に、必ず止まって確認させる。指示書に書く“お願い”ではなく、仕組みとして止められます。
  • パスワードやAPIキーが画面に出そうになったら、自動で伏せ字にする。
  • 作業が終わるたびに「どのファイルを変えたか」を横に一覧で出すなど、自分が見たい表示を足す。

試し方

  1. Claude Codeを最新版に更新します。
  2. 下の文をそのまま貼ります。
  3. Claudeが作って入れてくれるので、その場で試して、動きが違えば直してもらいます。

そのまま貼れる文

modを1つ作ってください。
内容は「git push と、ファイルの削除を実行する前に、必ず止まって私に確認を取る」です。
作ったら入れて、実際に止まるかどうかを試してから、結果を報告してください。

気をつける点：modは安全装置の外で動きます。知らない人が配っているものは入れず、自分でClaudeに作らせたものか、信頼できる配布元のものだけにしてください。

出典：Anthropic公式ブログ「Customize Claude Code with mods」 ／ GIGAZINE（2026年10月2日）

Claude Code ・ Codex

Claude CodeとCodexの指示書が、1枚で済むようになりました

何が出たか

Claude Codeが9月18日の更新（バージョン2.1.277）から、Codexなどが使う指示書「AGENTS.md」も読むようになりました。フォルダに CLAUDE.md が無いときに、代わりに AGENTS.md を読みます。両方あるときは、これまで通り CLAUDE.md だけを読みます。

仕事でどう使えるか

  • Claude CodeとCodexを両方使っている場合、同じルールを2つのファイルに書かなくてよくなります。
  • ルールを直すのが1か所で済むので、片方だけ古いまま、という食い違いがなくなります。
  • スタッフや外注先がどちらのAIを使っても、同じルールで動かせます。

試し方

  1. 作業フォルダに CLAUDE.md と AGENTS.md があるかを見ます。
  2. どちらも無ければ、AGENTS.md を1枚作るだけでどちらのAIにも効きます。
  3. 両方ある、または CLAUDE.md だけある場合は、下の文を貼って1枚にまとめます。

そのまま貼れる文

このフォルダの指示書を1枚にまとめたいです。
CLAUDE.md と AGENTS.md を読み比べて、重複をなくして AGENTS.md にまとめてください。
CLAUDE.md には「@AGENTS.md」の1行だけを残してください。
書き換える前に、どこをどうまとめるかを先に見せてください。

気をつける点：CLAUDE.md と AGENTS.md の両方があると、AGENTS.md は読まれません。上の文のように CLAUDE.md から読み込ませる形にすると、両方のAIが同じ内容を読みます。

出典：DevOps.com「Claude Code Adds AGENTS.md Fallback」 ／ DEV Community「Claude Code v2.1.277 Reads AGENTS.md」

新しいAI

文章を書かないAI「Jev」が出ました。判断だけを速く返します

何が出たか

9月中旬、TypeSafe AIという会社が「Jev（ジェブ）」という新しい種類のAIを公開しました。創業者は、ChatGPTの開発に関わった元OpenAIの研究者です。ChatGPTやClaudeのように文章を作るのではなく、「はい・いいえ」「どれに当てはまるか」「点数」を、確からしさの数字つきで返します。

仕事でどう使えるか

  • 問い合わせの振り分け：届いたLINEやメールを「予約・キャンセル・クレーム・その他」に一瞬で分ける。
  • 口コミやアンケートの仕分け：良い評価・悪い評価・要対応を分けて、対応が要るものだけ人に回す。
  • AIの返事の点検：自動返信を送る前に「人に回すべき内容か」を判定させる、見張り役として使う。

試し方

  1. 今は開発者向けの提供だけで、画面で触って使うものではありません。自動化の仕組みの裏側に入れる部品です。
  2. 「うちの問い合わせを自動で振り分けたい」のように使い道が思い浮かんだら、越智までお声がけください。

気をつける点：「速くて安い」は開発元と一部の利用企業の発表です。費用については逆の報告も出ています。また、確からしさの数字が低い答えは当てにならないので、その場合は人に回す作りが必要です。

出典：TechCrunch（2026年9月18日）

今週のひとこと

話題が変わったら、会話を新しくする

Claude Codeは、1つの会話が長くなるほど、毎回読み直す量が増えて使用量が増えます。別の作業に移るときは /clear と打つ（デスクトップアプリなら新しい会話を始める）だけで、上限に当たりにくくなります。指示書（CLAUDE.md）も、必要なことだけに絞って200行以内が目安です。どちらもClaude Codeの公式の案内です。

出典：Claude Code公式ドキュメント「Manage costs effectively」
